// capabilities

Built for precision.
Designed for humans.

RAG-Enhanced Retrieval

Retrieval-Augmented Generation pulls the most relevant parallel corpus examples before every translation, injecting few-shot context that dramatically improves accuracy and idiomatic fidelity.

Real-Time Translation

Powered by Llama 3.3 70B via Groq's blazing-fast inference API. Submit text and receive a high-quality translation in seconds — not minutes.

Language Detection

Automatic source language detection using offline langdetect — no API calls, no extra cost. Know what you're translating before you even select a target.

Rate Limiting & Safety

Built-in in-memory rate limiting (10 req/IP/60s) and robust error handling for cold-start delays, auth errors, and API failures — production-grade from day one.

FAISS Vector Search

Facebook's FAISS library provides lightning-fast in-memory vector similarity search across the parallel corpus — fulfilling the Vector Database role without any standalone database service.

100% Free Stack

Zero paid APIs. Sentence-transformers run locally for embeddings. Groq's free tier powers LLM inference. Open-source from embeddings to output.

// process

Four steps.
One fluent translation.

01

Embed Your Input

Your text is vectorized locally using sentence-transformers/all-MiniLM-L6-v2 — a compact, highly efficient model that runs entirely on your server with zero external API calls.

02

Retrieve Corpus Examples

FAISS searches the in-memory parallel corpus index for the most semantically similar translation examples in your target language — pulling just the right few-shot context for the LLM.

03

Build the Prompt

Retrieved examples are assembled into a structured few-shot instruction prompt — giving Llama 3.3 70B exactly the linguistic context it needs to generate an idiomatic, accurate translation.

04

Return the Translation

The Groq inference API responds with a clean translation. GeoSpeak strips any model preamble, displays the result, and gives you a one-click copy — ready to use instantly.
